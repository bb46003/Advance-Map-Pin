<h1>Advance-Map-Pin</h1>
<p>This module adds new features to Map Pins, such as:</p>
<ul>
<li>Pin labels are always visible without hovering</li>
<li>Add a custom overlay with your own text and/or image</li>
<li>Customize the position of the custom overlay</li>
<li>Text for the custom overlay uses ProseMirror text editing, giving you full flexibility in how your text looks</li>
<li>Set the background color of the custom overlay as you wish</li>
<li>Allow hiding labels on hover</li>
<li>Hide or show pins for specific players even without linking to a Journal</li>
<li>Allow removal of pin background and border</li>
<li>Scale Map Pin labels dynamically based on Canvas Zoom</li>
<li>Configure minimum and maximum font sizes for Map Pin labels depending on the current zoom level</li>
<li>Set how long Custom Overlays remain visible after moving the mouse away from the Map Pin or Custom Overlay</li>
<li>Limit the maximum width of all Custom Overlays using a world setting available only to Game Masters</li>
</ul>
